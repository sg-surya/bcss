## 🎯 About the Project

The **Bhavna Institute Platform** is a meticulously crafted web application built to modernize digital education interactions. Moving away from generic templates, this project utilizes a bespoke design system featuring glassmorphism, fluid typography, and precise micro-animations. It acts as the primary digital footprint for students, offering an intuitive course catalog, dynamic placement timelines, and seamless navigation.

## ✨ Key Features

- **Immersive Hero Section** - Captures attention instantly with mobile-first floating UI elements.
- **SaaS-Grade Aesthetics** - Harmonious color palettes and modern typography for a premium feel.
- **Dynamic Animations** - Powered by Framer Motion, providing contextual micro-interactions that enhance UX.
- **Responsive "Bento Grid" Layouts** - Ensures optimal viewing across desktops, tablets, and mobile devices.
- **Optimized Performance** - Built on Vite for lightning-fast HMR and highly optimized production builds.

## 🛠 Technology Stack

This project is built utilizing a modern, scalable frontend ecosystem:

### Core
- **React 19** - UI component architecture
- **TypeScript** - Static typing for robust code (where applicable)
- **Vite 6** - Next-generation frontend tooling

### Styling & UI
- **Tailwind CSS v4** - Utility-first styling framework
- **Framer Motion** - Production-ready animation library
- **Lucide React** - Clean and consistent icon set
- **React CountUp** - Engaging numerical data animations

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

You must have [Node.js](https://nodejs.org/) installed on your machine.
- Node.js (v18.0.0 or later)
- npm (v9.0.0 or later)

### Installation

1. **Clone the repository** (or navigate to your local working directory):
   ```bash
   cd bhavna-institute
   ```

2. **Install NPM packages**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```
   > The app will be available at `http://localhost:3000`

## 📦 Deployment

To compile the application for production:

```bash
npm run build
```
This command generates a `dist` directory containing your minified and optimized build.
To preview the production build locally:

```bash
npm run preview
```
